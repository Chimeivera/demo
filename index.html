這堂課我們要串接什麼？

GitHub Pages：正式操作入口 → Apps Script：接收操作、驗證權限 → Google 試算表：集中保存資料。

這次直接使用 GitHub 網址：網頁留在 GitHub Pages，透過 Apps Script 的唯讀 JSONP 與 POST 表單橋接功能讀寫 Google 試算表。管理密碼只傳送到後端驗證，不寫進 GitHub 檔案。

課堂專用：公開網址可被其他人開啟，資料可能被任意訪客讀取；請只輸入虛構資料，勿放正式院內業務資訊或個人資料。
